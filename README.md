# Event Coffee Batches

Plan coffee service by guest count, serving size and brewer capacity.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Guests = 40, Cups per guest = 1.5, Cup volume (ml) = 200, Brewer capacity (L) = 3. The first result is 4.
